❌ Tic Tac Toe

🎮 Live Demo: https://vencasmet.github.io/tictactoe/

A classic Tic Tac Toe game built using HTML, CSS, and JavaScript — perfect for learning the fundamentals of DOM manipulation, game logic, and UI interaction in browser games.

🧠 Project Overview

This is a browser-based implementation of the Tic Tac Toe game where two players can play against each other by clicking on the grid. The game handles:

Player turns (X and O)

Win detection across rows, columns, and diagonals

Draw detection

Game reset

The goal of the project is to demonstrate basic game logic and UI interaction in a web environment.

🚀 Features

✔️ Classic 3×3 Tic Tac Toe board
✔️ Player turn tracking (X / O)
✔️ Win and draw detection
✔️ Play again / reset support
✔️ Clean visuals with responsive design

🛠️ Tech Stack

HTML – Page structure

CSS – Styling and responsive layout

JavaScript – Game logic and DOM events

🎮 How It Works

User clicks on a cell

Current player’s mark (X or O) is placed

Game checks for win or draw after each move

If win is detected, game announces winner

If board fills without a winner → Draw

“Reset” restarts the game

▶️ How to Play (Local)

You can also run it locally:

    git clone https://github.com/VenCasMet/tictactoe.git
    open index.html


Then open the game in your browser 👾
